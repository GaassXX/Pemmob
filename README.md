# Pemmob

Repository ini berisi kumpulan proyek dan latihan Pemrograman Mobile berbasis Flutter yang dibuat selama perkuliahan. Setiap folder mewakili satu pertemuan atau tugas yang berbeda, dengan fokus pada pembelajaran dasar hingga aplikasi mobile yang lebih kompleks.

## Daftar Materi

- `pertemuan1` — Pengantar Flutter dan konsep dasar aplikasi mobile
- `pertemuan2` — Layout dan widget dasar
- `pertemuan3` — Interaksi user dan state dasar
- `pertemuan4` — Navigation dan pengelolaan layar
- `pertemuan5` — Data dan logika aplikasi lebih lanjut
- `pertemuan6` — Implementasi lanjutan dan proyek akhir pertemuan

## Teknologi

- Flutter
- Dart
- Android / iOS / Web support sesuai konfigurasi tiap proyek

## Struktur Repository

```bash
Pemmob/
```

## Cara Menjalankan Proyek

Pilih folder pertemuan yang ingin dijalankan, lalu jalankan perintah berikut:

```bash
cd pertemuanX
flutter pub get
flutter run
```

Ganti `X` dengan nomor pertemuan yang ingin dibuka, misalnya `pertemuan1` atau `pertemuan6`.

## Tujuan Project

Repository ini dibuat untuk:

- belajar konsep dasar pemrograman mobile menggunakan Flutter
- melatih pembuatan UI dan interaksi user
- menyiapkan portofolio praktikum selama perkuliahan
